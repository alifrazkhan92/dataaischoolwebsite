# DAIS AI Chat - Cloudflare Worker Setup

Follow these steps once to deploy the AI chat backend. Takes about 10 minutes.

## Prerequisites

- Node.js installed (https://nodejs.org)
- A free Cloudflare account (https://cloudflare.com)
- An Anthropic API key (https://console.anthropic.com)

## Step 1: Install Wrangler (Cloudflare CLI)

Open Terminal and run:

```
npm install -g wrangler
```

## Step 2: Log in to Cloudflare

```
wrangler login
```

A browser window opens. Log in with your Cloudflare account.

## Step 3: Deploy the Worker

From inside the `cloudflare-worker/` folder:

```
cd /path/to/dataaischoolwebsite/cloudflare-worker
wrangler deploy
```

After deployment, Wrangler prints a URL like:
`https://dais-chat.YOUR-SUBDOMAIN.workers.dev`

**Copy this URL.** You need it in Step 5.

## Step 4: Set your Anthropic API key as a secret

```
wrangler secret put ANTHROPIC_API_KEY
```

When prompted, paste your Anthropic API key (starts with `sk-ant-...`).

## Step 5: Update the Worker URL in chat.js

Open `js/chat.js` in the website repo. Find this line near the top:

```javascript
var WORKER_URL = 'https://dais-chat.REPLACE_WITH_YOUR_SUBDOMAIN.workers.dev';
```

Replace it with your actual URL from Step 3, for example:

```javascript
var WORKER_URL = 'https://dais-chat.alifrazkhan92.workers.dev';
```

## Step 6: Update the CSP in index.html

Open `index.html`. Find the Content-Security-Policy meta tag.
In the `connect-src` section, replace `REPLACE_WITH_YOUR_SUBDOMAIN` with your actual subdomain:

```
connect-src 'self' ... https://dais-chat.YOUR-SUBDOMAIN.workers.dev ...
```

## Step 7: Push website changes to GitHub

```
git add .
git commit -m "feat: add DAIS AI chatbot"
git push
```

GitHub Pages will update automatically within a minute.

## Step 8: Test it

Visit https://www.dataaischool.com and click "Talk to my AI". Ask a question about courses.

## Re-deploying after changes

Any time you edit `worker.js`, run `wrangler deploy` again from the `cloudflare-worker/` folder.

## Updating the knowledge base

The knowledge base (`ai-knowledge-base.txt`) is automatically regenerated by a GitHub Action
every time you push changes to any HTML file. No manual steps needed.

To manually update: edit `ai-knowledge-base.txt` and commit it. The Worker fetches the latest
version from GitHub every hour.

## Cost

- Cloudflare Workers free tier: 100,000 requests per day (more than enough)
- Anthropic API: approximately $0.002 per conversation (billed monthly)
- You only pay when visitors actually use the chat

## Support

If the chat stops working, check:
1. Cloudflare dashboard > Workers > dais-chat > Logs
2. That your Anthropic API key has credit/is active at console.anthropic.com
3. That DEPLOYMENT_URL in wrangler.toml matches your Worker URL
